# Mars 设计系统

> Mars 的界面规范：苹果式高级极简、本地优先的工作台工具。
> 本文档与 `assets/brand/brand-board.html` 保持同步，是前端实现时的唯一设计依据。

## 1. 设计原则

1. **安静高级**：界面服务于记录与回顾，不做营销化 Banner、不做装饰性插画；信息层级靠字体、间距与色彩完成。
2. **纸感 + 玻璃**：浅色模式呈现暖白纸感与轻玻璃层级，深色模式呈现深暖黑与高透玻璃，始终保持克制的半透明质感。
3. **4pt 网格**：所有间距、尺寸、圆角遵循 4 的倍数；元素稳定，不随内容抖动。
4. **锈红克制使用**：主色只用于当前选中、关键操作、数据高亮，屏幕内主色面积通常不超过 10%。
5. **即时反馈**：按压反馈 100ms 内出现；所有操作可撤销或可恢复，避免破坏性动作缺乏确认。

### 2.2 数据可视化色板

多系列图表依次使用：`#C3451F`、`#5B6670`、`#4C8A5C`、`#C98A1D`、`#8E6E8F`、`#FF6B3D`。
网格线使用 `var(--line)`，坐标轴文字使用 `var(--text-tertiary)`，主系列一律使用 `var(--accent)`。

### 2.3 使用规则

- 浅色模式文字级强调使用 `--accent-ink`，不用 `--accent`，确保正文对比度 >= 4.5:1。
- 深色模式主按钮使用 `--accent`（`#FF6B3D`）+ `--accent-contrast`（深墨文字）。
- 成功/警告/危险色只用于状态，不作为品牌装饰色。
- 禁止大面积铺满锈红；背景保持暖白/深暖黑，冷灰承担结构性信息。

## 3. 字体与字号

字体栈：`"Segoe UI Variable Display", "Segoe UI", Inter, "Microsoft YaHei UI", sans-serif`。
数字与时间使用等宽栈：`"Cascadia Mono", "SFMono-Regular", Consolas, monospace`。

| 样式 | 字号/行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| Display | 28/36 | 600 | 今日工作台标题、周报大数字 |
| Title | 20/28 | 600 | 页面标题、项目名 |
| Heading | 16/24 | 600 | 区块标题 |
| Body | 14/22 | 400 | 正文、表单、列表 |
| Small | 12/18 | 400 | 说明、表头、标签辅助文字 |
| Caption | 11/16 | 400 | 时间戳、角标 |
| Mono | 13/20 | 400 | 时长、日期、编号 |

规则：字母间距恒为 0；字号不随视口宽度缩放；正文行高不小于 1.5；数字开启 `font-variant-numeric: tabular-nums`。

## 4. 间距与布局

4pt 网格：`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64`。

- 侧边栏宽 `232px`，顶栏高 `52px`。
- 主内容区最大宽 `1120px`，左右栅格间距 `24px`。
- 页面内垂直间距：区块间 `32px`，区块内 `16-24px`。
- 列表行高 `44px`，输入控件高 `36px`，图标按钮 `32x32px`。
- 按钮文字不换行；图标按钮使用稳定尺寸，不因内容变形。

## 5. 圆角、边框与层级

- 卡片、按钮、输入框、面板：`8px`。
- 弹窗：`12px`（单个独立浮层可略大于卡片）。
- 标签、进度、开关：胶囊 `999px`。
- 应用图标：`rx = 224/1024`（由 Tauri 图标生成）。
- 边框统一 `1px`；浅色模式 `--line`，深色模式半透明白。

层级与玻璃：

```css
--shadow-1: 0 1px 2px rgba(43,26,19,0.06), 0 8px 24px rgba(43,26,19,0.06);
--shadow-2: 0 2px 6px rgba(43,26,19,0.08), 0 18px 48px rgba(43,26,19,0.14);
--glass: backdrop-filter blur(20px) saturate(160%);
--glass-strong: backdrop-filter blur(24px) saturate(180%);
```

深色模式阴影使用 `rgba(0,0,0,0.28)` 系，玻璃底色见 `--surface-glass`。玻璃层必须保留 `1px` 高光描边：浅色 `rgba(255,255,255,0.55)`，深色 `rgba(246,239,230,0.10)`。

## 6. 组件规范

### 6.1 导航

- 侧边栏使用 `--bg-raised` 或玻璃层，宽度固定 `232px`。
- 导航项高 `36px`，圆角 `8px`，图标 `18px`，文字 `14px`。
- 选中态：浅色 `--accent` 底 + `--accent-contrast` 文字；深色同理。
- 悬浮态：`--accent-soft` 半透明底；聚焦态追加 `2px` 焦点环。

### 6.2 顶栏

- 高 `52px`，玻璃材质，左侧显示当前视图标题，右侧放搜索、主题切换、设置等操作。
- 顶栏不显示产品功能介绍文字，只保留图标按钮（带 tooltip）。

### 6.3 按钮

- 主按钮：`--accent` 底，高 `36px`，圆角 `8px`，按下 100ms 内变暗并轻微下沉。
- 次按钮：`--bg-raised` + `--line` 边框。
- 幽灵按钮：透明，悬浮出现 `--accent-soft`。
- 图标按钮：`32x32px`，hover 显示 tooltip，focus 显示焦点环。

### 6.4 表单

- 输入框高 `36px`，圆角 `8px`，边框 `--line`，聚焦边框 `--accent` + `2px` 焦点环。
- 选择器（日期、项目、标签）使用原生风格 + 品牌化外壳。
- 数字/时长输入优先 stepper；二元设置使用开关或复选框；模式切换使用分段控件。

### 6.5 卡片与列表

- 卡片圆角 `8px`，边框 `--line`，背景 `--bg-raised`，内边距 `16px`。
- 表格行高 `44px`，hover 使用 `--accent-soft` 6% 透明度；主键列加粗。
- 标签：胶囊，高 `24px`，浅色底 `--accent-soft`、文字 `--accent-ink`。

### 6.6 弹窗与空态

- 弹窗宽 `420-560px`，圆角 `12px`，玻璃 + `--shadow-2`；确认框给出破坏性操作的风险说明。
- 空态：符号 + 一行说明 + 一个主操作，不使用大段引导文案。

### 6.7 图表

- 柱状/折线/热力图共用数据色板；默认显示最近 14 天。
- 柱状图柱宽固定，hover 高亮对应项目；热力图单元格固定宽高比。
- 所有图表带 `aria-label` 或等价文本摘要，颜色不是唯一信息通道。

## 7. 动效

- 按下反馈：`100ms`，`transform scale(0.985)` 或背景变深。
- 面板/视图切换：`200-300ms`，`cubic-bezier(0.32,0.72,0,1)`。
- 玻璃悬浮层出现：`160ms` 淡入 + 上移 `4px`。
- 尊重 `prefers-reduced-motion`：关闭位移与长动画，仅保留淡入淡出。

## 8. 可访问性

- 正文对比度 >= `4.5:1`；大字号与图标 >= `3:1`；焦点环在任何主题下可见。
- 全部交互支持键盘：Tab 顺序、Enter/Space 激活、Esc 关闭弹窗。
- 图标按钮必须有可读名称（`aria-label` 或 tooltip）。
- 状态不只用颜色表达：成功/失败同时显示文字或图标。
- 目标尺寸不小于 `32x32px`；点击热区不小于 `44x44px`。

## 9. 主题实现

- 主题状态存 `settings`，首次启动跟随 Windows 系统设置。
- 根节点使用 `data-theme="light|dark"`，令牌集中在 `:root` 与 `[data-theme="dark"]`。
- 切换主题不重建页面，只替换令牌；图表颜色跟随令牌实时更新。
- 玻璃材质在低性能设备上提供降级：关闭 `backdrop-filter` 并提升底色不透明度到 `0.96`。

## 10. 与品牌资产的关系

- 应用图标、侧边栏 Logo、空态符号统一使用 `assets/brand/` 中的图形。
- 符号最小 `16px`，横版字标最小 `48px`；深浅主题各用对应变体。
- Logo 不渐变、不拉伸、不加外框；详情见 `docs/技术选型与开发流程.md` 第 2 节。
